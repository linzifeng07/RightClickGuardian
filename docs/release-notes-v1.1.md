## 右键小守卫 v1.1

这是首次公开发布版本，包含完整源码和可直接运行的 Windows 程序。

### 主要能力

- 深度扫描传统注册表、文件格式专属菜单和现代应用菜单；
- 关闭并持续压制会被第三方软件重新写回的右键项目；
- 显示应用/文件图标，隐藏冗长 GUID 和技术标识；
- 提供多种文件类型的“右键实验室”真实预览；
- 支持策略恢复、核心项提示和登录自动守护。

### v1.1 流畅度优化

- 全部项目首批只创建 48 张卡片；
- 向下滚动时每批加载 36 项；
- 搜索增加 180ms 防抖；
- 图标结果复用；
- 开关项目只刷新当前卡片。

### 系统要求

- 64 位 Windows 10/11；
- .NET Framework 4.8；
- 运行时需要管理员权限。

下载下方 ZIP，解压后运行 `右键小守卫.exe`。
