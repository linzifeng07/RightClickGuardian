# 右键小守卫 v1.3.0

这次更新把软件整体切换为银发粉色系角色主题。

## 新主题

- 银白偏紫长发、双粉蝴蝶结和粉色衣服成为新的品牌形象。
- 主界面采用奶油粉、玫瑰粉、银紫和薄荷绿色，保持文字清晰。
- 首页、标题栏、窗口任务栏、托盘和空状态统一显示同一角色。
- 图标包含 16、24、32、48、64、128、256 像素版本。

## 稳定性

- 角色素材嵌入程序，不需要随软件额外携带图片。
- 新增主题资源、窗口快照和托盘图标自查。
- 保留 v1.2.3 的分批渲染与图标缓存，点击分类和软件专区仍保持流畅。

下载 ZIP 后解压，运行 `右键小守卫.exe` 即可。
